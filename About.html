About Melody Web

Melody Web is a modern, web-based music player that lets you discover and play tracks from the Jamendo music library. Designed with a sleek, dark theme and a responsive layout, Melody Web brings you a smooth and enjoyable listening experience on any device.

Features:

  • Browse and play popular tracks from Jamendo
  • Infinite scroll for endless music discovery
  • Responsive and accessible design
  • Live progress bar and time display
  • Volume control and playback controls
  • Modern, customizable color scheme

Technologies Used:

  • HTML5, CSS3 (with CSS variables for easy theming)
  • Vanilla JavaScript (ES6+)
  • Jamendo Public API
