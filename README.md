# 🎧 Melody Web

**Melody Web** is a dynamic music player web app that streams royalty-free tracks using the [Jamendo API](https://developer.jamendo.com/). It features a modern dark-themed UI, real-time audio controls, infinite scroll, and responsive design — perfect for showcasing your frontend skills.

---

## 🚀 Features

- 🎵 **Live Music Streaming** via Jamendo API  
- 🔁 **Infinite Scroll** — loads more songs as you scroll  
- 🎛️ **Play/Pause/Seek/Volume Control**  
- 🕓 **Real-Time Timestamp** (current time / total duration)  
- 🎧 **Stylish Custom UI** with animated visuals  
- 💻 **Responsive Design** — works well on mobile too  
- 🌑 **Dark Theme** with custom scrollbar and clean layout
